# Utility & Migration Scripts (`scratch/`)

This directory contains standalone Python maintenance and migration scripts used during module generation and batch transformations:

- `enrich_biology.py`: Enriches Swedish plant botany data from iNaturalist APIs.
- `extract_prereqs*.py`: Prerequisite extraction utilities.
- `fix_formulae.py` & `update_formula_includes.py`: Batch syntax fixes for Typst formula pages.
- `generate_mvc_questions.py`: Initial generator script for the Multivariable Calculus problem bank.
- `map_prereqs*.py`: Prerequisite mapping generators.
- `replace_deprecated_symbols.py`: Batch replacement of deprecated Typst symbols.
- `set_difficulty.py`: Difficulty level assignment across question metadata.
- `update_metadata.py`: Batch metadata updates for question JSON schemas.
